# Chanduni Bootawatta — Portfolio

A dark, lavender-accented React + Vite portfolio starter inspired by the supplied reference image.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Extract this project folder.
3. Open the folder in VS Code.
4. Open Terminal → New Terminal.
5. Run:

   ```bash
   npm install
   npm run dev
   ```

6. Open the local URL printed by Vite (usually http://localhost:5173).

## Personalise before publishing

- Replace `your.email@example.com` in `src/App.jsx` with your email.
- Replace the LinkedIn `href="#"` with your profile URL.
- Add your CV as `public/Chanduni-Bootawatta-CV.pdf`.
- Review the internship dates and project description.
- Add further projects and verified achievements.

## Build for deployment

```bash
npm run build
```

The production website is generated in the `dist` folder. You can deploy the project to Vercel by importing its GitHub repository.
